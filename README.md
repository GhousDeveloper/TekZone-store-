# TekZone — Better Tech • Better Life

### A Modern Multi-Category E-Commerce Marketplace

A responsive storefront built with React 19 and TypeScript. It covers product discovery, filtering, a six-step checkout, a customer account portal, and dedicated seller and admin dashboards, across electronics, fashion, home, beauty, gaming, sports and more.

## ✨ Features

### 🛍️ Storefront
- Hero carousel, shop-by-category tiles and category mega-sidebar
- Flash deals with a countdown timer, Best Sellers and Trending Now sections
- Top brands strip, promotional banners and a newsletter signup banner
- Header search with category selector, wishlist and cart counters

### 🔎 Product Discovery
- Category and brand filtering
- Max-price slider, minimum-rating and minimum-discount filters
- In-stock-only toggle and sorting options

### 📦 Product Details
- Image gallery with quantity stepper, **Add to Cart** and **Buy Now**
- Tabs for description, specifications, reviews, and questions &amp; answers
- Related products and recently viewed items

### 🛒 Cart &amp; Checkout
- Cart quantity management and save-for-later
- Coupon codes (for example the `WELCOME` code shown in the header)
- Six-step checkout: customer info → shipping address → delivery → payment → order review → confirmation

### 👤 Customer Portal
- Dashboard, order history and order tracking timeline
- Wishlist, saved addresses, payment methods and reviews
- Notifications, support and account settings

### 🏪 Seller Hub
- Overview, product list and add-product form
- Orders, inventory, customers, reviews and coupons
- Analytics, payments and store settings

### 🛡️ Admin Console
- Dashboard, products, orders, customers and sellers
- Categories, brands, banners, reviews and coupons
- Payments, returns, reports and settings

| Technology | Purpose |
|---|---|
| React 19 | Component-based user interface |

## 🚀 Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/GhousDeveloper/TekZone-store-.git
```

**2. Enter the project folder**

```bash
cd TekZone-store-
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the app** at [http://localhost:3000](http://localhost:3000)

Other scripts: `npm run build` (production build), `npm run preview` (preview the build), `npm run lint` (type-check with `tsc --noEmit`).

## 📌 Implementation Notes

TekZone is a polished **frontend** showcase. To keep expectations clear:

- **Persistence:** cart, wishlist, orders and products are saved in the browser's `localStorage`. Data stays on that device and browser and does not sync across devices or users.
- **Checkout:** the checkout flow and payment options (card, cash on delivery, digital wallet) are a user-interface experience. No payment gateway is integrated and no real payments are processed.
- **Accounts, seller and admin areas:** there is no backend or authentication. The seller and admin dashboards are interface demonstrations with sample data, not permission-enforced areas.
- **Sample data:** products, reviews, orders and dashboard figures are demo data defined in `src/data/storeData.ts` and the dashboard components.

These are natural next steps for a production version: a backend API, a database, real authentication and a payment provider.
