## ✨ About TekZone

TekZone is a modern e-commerce project designed to provide a polished online shopping interface alongside a dedicated seller dashboard.

The project focuses on a clean user interface, organized layouts, and a smooth browsing experience.

## 🚀 Highlights

| Feature | Description |
|---|---|
| 🛍️ E-commerce Interface | Modern online store design |
| 📊 Seller Dashboard | Dedicated seller-facing dashboard |
| 📱 Responsive UI | Designed with a modern web experience in mind |
| ⚡ Modern Frontend | Built with a modern JavaScript and TypeScript toolchain |
| 🎨 Clean Design | Organized layouts and polished visual styling |

## 💻 Run the Project Locally

Make sure Node.js and npm are installed on your computer.

**1. Clone the repository**

```bash
git clone https://github.com/GhousDeveloper/TekZone-store-.git
```

**2. Open the project directory**

```bash
cd TekZone-store-
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the project.
